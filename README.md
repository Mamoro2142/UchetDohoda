# Учёт дохода

Android-приложение на Kotlin и Jetpack Compose для учёта заработка по вахтам.

## Добавлено в обновлённой версии исходников
- Начало и завершение вахт с отдельными записями каждой вахты.
- Редактирование и удаление дневных записей.
- Учёт авансов и штрафов в рамках активной вахты.
- Статистика по месяцам и итоги по каждой вахте.
- Перенос старых дневных записей из прежнего формата хранения при первом запуске.

## Сборка
Откройте проект в Android Studio и дождитесь синхронизации Gradle, затем выберите **Build > Build APK(s)**.
